# Texas Hold'em — Mesa de Amigos

Proyecto web funcional para 2–10 jugadores.

## Ejecutar
Necesitas Node.js 18+.

```bash
npm install
npm start
```

Luego abre `http://localhost:3000`.

Para que tus amigos entren desde la misma red Wi‑Fi, abre el puerto 3000 del equipo servidor y usa su IP local, por ejemplo `http://192.168.1.20:3000`.

## Incluye
- Mesa visual de Texas Hold'em.
- 2–10 jugadores.
- Código de mesa.
- Fichas virtuales.
- Cartas privadas y comunitarias.
- Turnos.
- Fold, check/call y raise.
- Flop, turn y river.
- Evaluación de manos y showdown.
- Panel del crupier.
- Reinicio de fichas.
- WebSockets para sincronización en tiempo real.

No incluye dinero real, depósitos ni retiros.
